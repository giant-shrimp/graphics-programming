# 第13・14回：おもしろアプリコンテスト

Processing で自作したアプリ（ゲーム）を作り，受講生同士で相互評価するコンテストです．

## コンテストの規程（概要）

- アプリのプログラムと解説スライドを提出する（解説スライドはこのリポジトリには含めていません）．
- 何らかの形でクラスを用いる．
- プログラムには詳細なコメントをつける．
- 既存アプリを改良する「改良」部門と，自分で考えたアプリを作る「開発」部門がある．

## スケッチ

[`omoshiroApp_2022531063`](omoshiroApp_2022531063/) — **Don't Collide（衝突しないで）**

縦スクロールのアクションゲームです．前方から来る対向車を避け続けます（900×900）．
外部ライブラリや外部ファイルは必要ありません．

### 特徴

- 自分の車を `Car` クラスで表現．走行レーンや車体の色をメンバ変数として持たせています．
- タイトル画面で車の色（R/G/B）をカスタマイズできます．
- スピードメーター（針が速度に合わせて動く）を備え，速く走るほどスコアが伸びる一方，対向車も速くなります．
- スコアが上がるごとにレベルが上がり，対向車が速くなります．
- 対向車が同じレーンに重ならないよう，レーンの使用状況を管理しています．

### 遊び方

1. タイトル画面で，自分の車の色（R/G/B）をキーで調整します．
2. `Enter` でゲーム開始．カウントダウンの後，対向車が走ってきます．
3. 3 本のレーンを移り変わりながら，対向車をよけ続けます．
4. 対向車に衝突するとゲームオーバー．`Enter` で再挑戦できます．

### 操作方法

| キー | 動作 |
| --- | --- |
| `Enter` | ゲーム開始 / ゲームオーバー後に再開 |
| `A` / ← | 左のレーンへ移動 |
| `D` / → | 右のレーンへ移動 |
| `W` / ↑ | 加速（スピードメーターの上限あり） |
| `S` / ↓ | 減速（下限あり） |
| `1` / `2` | 車の色 R を −1 / +1（タイトル画面のみ） |
| `3` / `4` | 車の色 G を −1 / +1（タイトル画面のみ） |
| `5` / `6` | 車の色 B を −1 / +1（タイトル画面のみ） |
