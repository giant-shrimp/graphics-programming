## 必須課題01: 波紋

マウスをクリックした位置から，ランダムな色のリングが広がっていきます（400×400）．
複数のリングを同時に表示でき，リングは最大 100 個まで保持します．大きくなりすぎたものは描画されなくなります．

| 操作 | 動作 |
| --- | --- |
| マウスクリック | クリック位置に新しいリングを生成 |

- **初版（`p5_day2_kadai01_2022531063`）**: 使用済みのリング数 `useRing` まで描画し，100 個に達したら 0 に戻す．
- **修正版（`day2_kadai1_2022531063_re`）**: 描画ループを全リング（`NumOfRing`）に対して回し，
  未使用のリング（サイズ 0）は描画しないようにした．`useRing` は `% NumOfRing` で循環させている．

## 必須課題02: 揃ったマシーン（スロット）

3 つのリールが異なる速さで回転し，キーで 1 つずつ止めていきます（400×400）．
左と中央が揃うとリーチになり，背景色が変化します．3 つ揃えば成功です．

| キー | 動作 |
| --- | --- |
| ↓ | 矢印が指しているリールを止め，矢印を次のリールへ進める |
| ← | 全リールが止まった後，ゲームを初期化して再開 |
| Shift | （矢印が右端にあるとき）3 つを強制的に揃えるチェック機能 |

## Extra01: フーリエ級数展開の可視化（`day2_extra_2022531063_re`）

矩形波をコサイン級数（係数 `a0`〜`a19`）で近似し，その様子を 3 つのグラフで表示します（800×800）．

- 上段: 元の矩形波（黒）とフーリエ級数（黄）
- 中段: 両者の差分（青）
- 下段: 各フーリエ係数（黄色の点）．選択中の係数を矢印で表示

| キー | 動作 |
| --- | --- |
| → / ← | 着目する係数を移動 |
| ↑ / ↓ | 着目する係数を 0.01 ずつ増減 |
| 1 | 理論式から求めた係数を一括で設定 |
| 0 | 係数をすべて 0 にリセット |
