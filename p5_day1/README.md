## 練習①（`p5_day1_rensyu1_2022531063`）

冒頭の変数 `cpNum`（1〜9）を書き換えると，表示する練習が切り替わります．各関数内のコメントに関数の使い方のメモがあります．

| `cpNum` | 内容 |
| --- | --- |
| 1 | 四角形（`rect`，`rectMode`） |
| 2 | 楕円（`ellipse`） |
| 3 | 線分（`line`，`stroke`，`strokeWeight`） |
| 4 | 変数 |
| 5 | 繰り返し（`for`） |
| 6 | 文字（`text`，`textAlign`） |
| 7 | 条件分岐（`if`） |
| 8 | 数学的な関数（`sin`，`cos`，`radians`）で正三角形を描く |
| 9 | 配列 |

## 必須課題（`p5_day1_kadai_2022531063`）

`setup()` / `draw()` 内の呼び出しのコメントアウトを切り替えて，確認したい課題を表示します（初期状態は `kadai_01`）．
課題の条件として，`rotate()` は使わずに作ることになっていました（五芒星・アナログ時計）．

| 関数 | 内容 | 呼び出し場所 |
| --- | --- | --- |
| `kadai_01` | `#`（シャープ）記号（描く順番がポイント） | `setup()` |
| `kadai_02` | 市松模様（二重 `for` と奇数・偶数の判定） | `setup()` |
| `kadai_03` | 五芒星（半径 50 px の円に内接．72° ずつ頂点を結ぶ） | `setup()` |
| `kadai_04` | 正弦波状の縞（横縞） | `setup()` |
| `kadai_05` | アナログ時計（秒針・長針・短針．`count` で回転） | `draw()` |
| `kadai_06` | 左から右へ動く輝度の縞 | `draw()` |

### 修正版（`day1_kadai_2022531063_re`）

初版からの変更点は次の 2 つです．

- `kadai_01`: 分割して描いていた四角形を 1 つに減らし，描画する四角形を 5 つに削減．
- `kadai_02`: `if` / `else` の両方に書いていた `rect()` を外に出して 1 回にまとめた．
