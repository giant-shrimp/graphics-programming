# Graphics programming

大学講義「情報システム工学実験Ⅱ」の後半（第9回〜第15回，2023年11月〜2024年1月）で取り組んだ，
[Processing](https://processing.org/) による描画プログラミングのスケッチ集です．

この講義の後半は「自分のアイデアを画像・映像・アプリケーションとして表現できる」ことを目標に，
Processing の基礎から，マウス・キー入力，クラス，3D，音声，そして自作アプリ制作までを扱いました．

## 内容の概要

- **第9回（day1）**: 図形・線・文字・変数・繰り返し・条件分岐・三角関数・配列といった基本的な描画．
  `#` 記号，市松模様，五芒星，正弦波の縞，アナログ時計，色相環など．
- **第10回（day2）**: マウス／キーボード入力を使ったインタラクション．
  クリックで広がる波紋，スロットゲーム，フーリエ級数展開の可視化．
- **第11回（day3）**: クラス（構造体）を使った書き方．
  車のアニメーション，9 マスのパスコードパズル，神経衰弱，3D 描画（P3D），電子ピアノ／音ゲー．
- **第12回**: スマートフォン用壁紙（360×640）をランダムな図形で生成．
- **第13・14回**: 自作ゲーム「Don't Collide」．

## 動かし方

1. [Processing 4](https://processing.org/download) をインストールします（開発時は Processing 4.3）．
2. 各スケッチのフォルダ（例: `p5_day1/p5_day1_rensyu1_2022531063/`）を Processing で開くか，
   中の `.pde` ファイルをダブルクリックします．
3. 実行ボタン（▶）で起動します．

Processing では「フォルダ名と同名の `.pde` ファイル」が 1 つのスケッチとして扱われます．
このリポジトリはそのルールに沿ったフォルダ構成のままです．

### 追加ライブラリが必要なもの

それ以外のスケッチは Processing 標準機能のみで動作します．
