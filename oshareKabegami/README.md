# 第12回：おしゃれ壁紙コンテスト

スマートフォン用の壁紙（360×640 px）を，プログラムで生成して見栄えを競うコンテストです．
受講生同士が，作者名を伏せた状態で画像だけを見て相互評価しました．

## コンテストの規程（概要）

- 画像サイズは 360×640 px に固定（`size(360, 640)`）．
- 講義資料・課題に出てきたものをそのまま使う，または色を変えただけにするのは不可．
- 画像ファイルの利用は不可（プログラムだけで描く）．
- 提出物は，プログラム・生成した壁紙画像・解説スライド（解説スライドはこのリポジトリには含めていません）．

## スケッチ

[`oshareKabegami_2022531063`](oshareKabegami_2022531063/)

パジャマの柄のように，円（緑）・三角形（赤）・四角形（黄）を 5 行 × 5 列に並べます．

- 図形の種類と，各図形の回転角はランダムに決まります．
- 奇数列は縦方向に半段＋ランダムな量（0〜9 px）ずらして配置します．
- 実行するたびに異なる柄になります．

## 出力画像

実行すると，スケッチフォルダに `myWallPaper_2022531063.png` を `saveFrame()` で保存します．

| ファイル | 内容 |
| --- | --- |
| `myWallPaper_2022531063.png` | 実行結果の一例 |
| `myWallPaper_.png` | 別の回の実行結果 |

> 実行のたびに画像が上書きされます．
